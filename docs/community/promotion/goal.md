# 目标：让 10 个真实外部用户成功交付一次

> 设定时间 2026-08-23，目标期 30 天（到 2026-09-22）。
> 起点基线（2026-08-22 实测）：0 star / 0 fork / 0 issue，14 天 2 个独立访客，npm 未发布，零遥测。

## 北极星目标

**30 天内，让 10 个真实外部用户用 DeliverKit 成功产出并验证过至少一个安装包。**

不是 star 数，不是浏览量。star 可以靠一次发帖冲上去，但它不证明这个项目有用。「有人用它真的把产品打成了包、装上了、跑起来了」才是 DeliverKit 存在的证明——这也正好是项目自己的第二条铁律（真实验证）应用到项目自身。

这个目标决定了优先级排序：**转化 > 流量**。先保证进来的人能成功，再去把人引进来。100 个访客里 10 个成功，比 1000 个访客里 0 个成功有价值得多。

### 判定方式（可验证，不靠感觉）

| 信号 | 来源 | 说明 |
|---|---|---|
| npm 周下载 ≥ 50 | `api.npmjs.org` 周快照 | 至少证明有人装了 |
| GitHub star ≥ 50 | metrics 周快照 | 流量侧的量级参考 |
| 目录收录 ≥ 4 处 | 收录链接回填 matrix.md | 持续自然流量的基础 |
| 外部 issue / discussion ≥ 3 条 | 仓库 | 有人认真用了才会提问 |
| 明确的成功反馈 ≥ 10 例 | issue / discussion / 社区回帖 | 用户说「跑通了」或贴出产物、ReleaseManifest |

第五项是北极星本身，前四项是它的先行指标。数据全部来自 `metrics/` 周快照与仓库本身，不靠自我评估。

## 三条战线

### 战线一 · 首次成功体验（TTFS ≤ 10 分钟）

流量落地即流失是冷启动项目最大的浪费。第二轮已完成的代码层改造全部服务于这条：

- `deliverkit doctor`：进门第一件事就是摊开「这台机器现在能交付什么、缺什么、怎么补」，把环境门槛前置到 5 秒内可知，而不是 15 分钟构建失败后才发现。
- 失败必须可自救：错误结果带 `log_excerpt`（日志尾部片段）、`suggested_fix`、`next_actions`。此前只返回一个日志路径，等于把排错成本转给用户，Agent 更是完全读不到原因。
- Docker 不可用细分四种原因（没装 / 守护进程没起 / 权限不足 / 探测超时），各给各自的修复动作。实测中「Docker Desktop 未启动」曾被误判成权限问题，已加真实报错文案的回归测试锁住。
- 超时不再伪装成普通构建失败，并提示预拉镜像——首次运行拉 2GB 镜像撞上超时上限时，用户不该去排查自己的代码。
- 项目侧检查（语言、包名）前置到 Docker 探测之前，语言不支持时不再白等一次守护进程探测。
- CLI 默认输出人类可读摘要，`--json` 保留结构化结果给 Agent 与脚本。
- MCP 响应设 `isError`，客户端无需解析 JSON body 就能识别失败。
- 未预期异常（权限、磁盘写满）落回统一错误结构并给出具体建议，不再变成一句裸的 InternalError。

### 战线二 · 渠道分发（先上架，再发声）

材料已全部就绪，见 [matrix.md](matrix.md) 与 [submissions/](submissions/)。执行顺序不变：目录收录（T0）→ 英文社区（T+1）→ 中文圈（T+1 周）。

阻断项只剩需要账号凭据的三件事，见 [gates.md](gates.md)：npm publish、METRICS_TOKEN、各社区账号。

### 战线三 · 证据沉淀

- `metrics/` 每周流量快照（已上线，GitHub Insights 只留 14 天，快照才能长期归因）。
- 每个 feature release 作为一次再曝光事件（Release 会通知所有 watcher）。
- 用户成功案例（产物截图 / ReleaseManifest.json）沉淀成社交证明，反哺战线二的文案。

## 不做什么

- **不做默认开启的遥测**。开源工具默认上报是信任红线。要回答「哪个工具用得最多」，只能做 opt-in 匿名计数（默认关闭，显式开关开启，不含路径与项目信息）。
- **不为了发帖而夸大能力**。Linux 三目标有 e2e + CI 证据；Windows / macOS / 鸿蒙是契约先行、签名门槛待对应 runner 验证。所有文案守这条口径。
- **不追求 star 曲线**。star 是先行指标，不是目标；把它当目标会导致优化发帖而不是优化产品。
