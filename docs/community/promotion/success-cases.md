# 真实成功案例台账

> 北极星目标：30 天内让 10 个真实外部用户成功产出并验证至少一个安装包。
> 只记录用户主动提供、可以公开或匿名公开的最小证据；不收集源码、私钥、完整本地路径或默认遥测。

## 记录规则

一次案例必须至少包含：

- 来源：GitHub issue / Discussion / 社区链接
- 用户自愿提供的匿名项目类型（例如 Node CLI、Go HTTP 服务）
- 目标生态与产物类型
- 是否完成安装验证、运行验证、签名验证（如适用）
- 可公开的证据链接或 `ReleaseManifest.json` 摘要
- 用户是否同意在宣传文案中匿名引用
