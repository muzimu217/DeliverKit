# DeliverKit 宣传矩阵（Promotion Matrix）

> 本目录是 DeliverKit 的市场推广作战室：渠道矩阵、发布门禁、各渠道成稿文案、目录提交材料、数据采集方案全部集中在这里。
> 建立时间：2026-08-22。当时基线：0 star / 0 fork / 0 issue，GitHub Insights 14 天窗口 24 次浏览（2 个独立访客），referrer 仅 github.com。

## 目录结构

| 文件 | 用途 |
|---|---|
| [matrix.md](matrix.md) | 宣传矩阵总表：对标体系、渠道矩阵、发布节奏、指标看板 |
| [gates.md](gates.md) | 发布门禁清单：对外宣发前**必须**完成的阻断项（npm publish、push 等） |
| [metrics.md](metrics.md) | 真实用户数据采集三层方案（含当日基线快照） |
| [copy/](copy/) | 各渠道成稿文案（英文渠道用英文稿，中文渠道用中文稿） |
| [submissions/](submissions/) | MCP 目录提交材料包（awesome-mcp-servers、官方 Registry、Smithery、Glama、mcp.so） |

## 使用方式

1. 先执行 [gates.md](gates.md) 的门禁清单（不通过则一切对外渠道都不要发，落地即流失）。
2. 门禁通过后，按 [matrix.md](matrix.md) 的 T0 → T+1 → T+1w 节奏逐渠道发布 `copy/` 里的成稿。
3. 每周一查看 `metrics/` 目录的流量快照 + [metrics.md](metrics.md) 的指标看板，复盘并调整渠道投入。
